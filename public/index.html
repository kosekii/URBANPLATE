Built for people who always ask where to eat

URBANPLATE gathers the restaurants stored in the dbRestaurants database into one place. Look a restaurant up by name or cuisine, group the list by country, and check which places have the strongest inspection scores.

Anyone can keep the list current. Add a new spot, edit the details of an existing one, or delete one that has closed. Every change is saved to MongoDB Atlas.
